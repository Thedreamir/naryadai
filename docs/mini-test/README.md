## Выводы (честно)

- Мультимодальная проверка фото сильная: 4/4 поймала несоответствие узла на фото описанию работ.
- Текстовая проверка мягкая: расплывчатые («Сделано всё.») и минимальные описания проходят — 8/8 ложных пропусков.
- Недетерминизм: идентичные категория-A закрытия дважды отклонены (модель искала кабель в материалах), дважды пропущены.
- Гарантия «внеплановый без фото не закрыть» на уровне БД: 4/4 заблокированы до ИИ.
- Быстрое «накрученное» время выполнения несимулируемо: started_at/closed_at ведёт только триггер — антифрод на уровне схемы.

Сырые ответы модели — ai2_*.json в этом каталоге.
