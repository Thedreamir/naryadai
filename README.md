# Tekton OS / НарядAI: приватный синтетический прототип

Ветка redesign содержит новую компоновку. Это не описание уже развёрнутой версии. Данные только синтетические, не промышленная система.

## Проверено в этой ветке 8 октября 2026

- Чистая установка npm ci, TypeScript/Vite сборка и 6 доменных тестов на локальной машине.
- Мастер и руководитель: локальные синтетические фикстуры на 390 и 1440 px, нет горизонтальной прокрутки, проверенные кнопки не ниже 44 px. Это не замер на телефоне.
- Радар повторных нарядов: временной holdout на синтетике. Регрессия 82.13%, постоянная база риска 82.40%. Модель хуже базы; физические отказы не подтверждает. См. docs/predictive.md.
- База знаний: миграция и UI в подготовке. 11 тестов на минимальной локальной схеме, транзакция откатывается. Это не проверка всей схемы Supabase. По умолчанию интерфейс скрыт; VITE_KNOWLEDGE_PREVIEW=true только для локального QA.
- Transformers.js: реальный локальный smoke-test multilingual-e5-small на двух синтетических русских пассажах. Это не оценка точности. PDF.js используется для извлечения текста PDF в браузере.

## Не подтверждено, не обещаем

- Новая ветка не опубликована; миграция 053 и новая assistant-chat не развёрнуты. Статус старого живого приложения отдельно от этой ветки.
- Web Push / Firebase / доставка на закрытый телефон отсутствуют. Баннер/звук в открытом приложении не называем push.
- Офлайн-очереди нет. PWA-оболочка не обеспечивает офлайн-изменение нарядов.
- Android APK и вызов поверх блокировки не построены и не проверены.
- QR использует текущий origin; localhost-код не откроется на другом телефоне. Публичный адрес требует отдельного разрешения.
- RU/KZ: черновая навигация; содержимое RU, перевода носителем нет.
- Нет настоящего замера 1 мин / 6 нажатий / 5 с / 10 с. Эти цифры остаются целями.
- ИИ-замер авторский: самопроверка, не независимое испытание и не оценка качества реального ремонта.
- Regex-маскирование не доказывает обезличивание. Реальные документы запрещены. Новая chat-функция по умолчанию rules-only; live-функция не менялась.

## Локальная проверка

Node 22+, npm. `npm ci`, `npm test`, `npm run build`.

UI требует конфигурации Supabase и собственного входа. Локальные screenshot-фикстуры не поставляются вместо живого data.ts. Секреты не публикуются. Не применяйте SQL из этой ветки в рабочую базу без проверки и отдельного решения владельца.

## Библиотеки, реально использованные в коде

React, TypeScript, Vite, Tailwind, Lucide, Supabase, qrcode. PDF.js и Transformers.js: Apache-2.0; multilingual-e5-small: MIT по карточке исходной модели. Это поисковые эмбеддинги, не генератор ответов. Hugging Face нужен для скачивания весов; текст обрабатывается локально. Пакет и модель проверены отдельно от установленных, но неиспользуемых библиотек.
