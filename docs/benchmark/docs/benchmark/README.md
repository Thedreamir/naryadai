# Как проверяли ИИ

Это проверка согласия модели `gemini-3.5-flash-lite` с предварительной разметкой, не точность на производстве.

## Метод

48 сгенерированных ИИ синтетических пар «до/после», в том числе 4 пары с разным оборудованием как отрицательные сложные примеры. Пары коррелированы и не образуют независимую промышленную выборку. 7 меток уточнены владельцем по превью; 41 метка поставлена ассистентом по рубрике без проверки человеком. Предварительные метки: 25 исправных случаев и 23 отрицательных.

Решение: принять, если `defect_visible=false`, `tools_left=false` и оценка 4 или 5; отклонить, если один из флагов `true` или оценка не выше 2; оценка 3 или неизвестное значение означают воздержание. Отсутствующие и некорректные ответы считаются отдельно. Положительный класс в отчётах - «принять».

## v1 и v2

| Показатель | v1 | v2 |
| --- | --- | --- |
| Валидные ответы | 48/48 | 48/48 |
| Бинарные решения | 45/48 | 48/48 |
| Воздержания | 3 | 0 |
| Согласие на бинарных решениях | 40/45 (88.9%) | 46/48 (95.8%) |
| Согласие по всем 48 случаям, воздержания не считаются верными | 40/48 (83.3%) | 46/48 (95.8%) |
| Приняты исправные случаи | 25/25 | 23/25 |
| Отклонены отрицательные случаи | 15/23 | 23/23 |
| Ложные приёмы отрицательных случаев | 5 | 0 |

В v1 промахи включали подмену оборудования и временные решения. В v2 добавлено общее защитное правило о тождестве оборудования и кустарных материалах. Правило настроено после анализа **того же набора**, затем проверено на нём же. Это улучшение на обучающем стресс-тесте, не независимый тест обобщения.

## Ограничения

- 95.8% - согласие с предварительными метками на синтетике, не подтверждённая производственная точность или безопасность ремонта.
- Большая часть меток не проверена человеком. Ошибки разметки могут менять результат.
- Интервал Wilson для v2: 86.0-98.8%; корреляция пар и ошибка разметки в нём не учтены. Он не доказывает обобщение.
- В v2 два исправных случая отклонены. Отсутствие ложных приёмов на этих 23 отрицательных примерах не гарантирует их отсутствие в других условиях.
- ИИ рекомендует. Окончательное решение принимает мастер. Human in the loop.
